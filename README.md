# Secure Wireless Network using Cisco Packet Tracer

This project demonstrates the design and implementation of a **secure wireless network** using **Cisco Packet Tracer**.

The main purpose of this project is to study wireless network architecture, device configuration, connectivity, and basic security mechanisms in a simulated environment.

## Project Objectives

- Design a wireless network topology
- Configure routers, switches, and wireless devices
- Configure IP addressing
- Establish wireless connectivity
- Apply basic wireless security mechanisms
- Test communication between devices
- Evaluate the security of the wireless network

secure_wireless_network.pkt
Cisco Packet Tracer file containing the complete network topology and device configurations.

## Network Security
The project focuses on basic wireless security concepts, including:
- Wireless access control
- Secure network configuration
- IP network segmentation
- Authentication
- Preventing unauthorized access
- Connectivity and security testing


## Requirements
To open and run the project, install:
- Cisco Packet Tracer

Then open:
secure_wireless_network.pkt

## Usage

1. Open Cisco Packet Tracer.
2. Open the `secure_wireless_network.pkt` file.
3. Inspect the network topology.
4. Check the configuration of routers, switches, access points, and end devices.
5. Run connectivity tests using tools such as `ping`.
6. Review the wireless security configuration.
